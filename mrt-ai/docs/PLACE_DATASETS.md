# Реальные места для пилотных регионов

На 2026-10-06 локальный каталог содержит снимок из 2 593 координатных объектов Wikidata: 1 219 назначены Москве и 1 374 Московской области. В выдаче есть музеи, памятники, церкви и монастыри, театры, парки, мосты и другие культурные/природные объекты. Источник и категории сохранены в каждой записи; при повторной загрузке число может измениться.

Снимок находится в `data/normalized/wikidata-places.json`. Cached-режим API читает его локально и не обращается в интернет во время запроса. OSM snapshot по-прежнему отдельный и пока не создан.

## Источник и использование

Данные получены SPARQL-запросом к [QLever Wikidata endpoint](https://qlever.dev/wikidata), который Wikidata перечисляет как альтернативный endpoint своего Query Service. Для каждой точки сохранена ссылка `https://www.wikidata.org/entity/Q…`; сами структурированные данные Wikidata доступны под [CC0 1.0](https://www.wikidata.org/wiki/Wikidata:Licensing). В снимке остаётся атрибуция участников Wikidata и хеш запроса.

Класс Wikidata переводится в `ATTRACTION` или `ACTIVITY` и в русские поисковые теги. Эти теги — наше правило классификации по типу объекта, а не оценка качества, популярности или соответствия интересам. Рейтинг и оценка пользователей не подставляются.

## География и ограничения

Выборка использует административную иерархию Wikidata (`P131+`) к Москве (`Q649`) или Московской области (`Q1697`). Регион определяется этой связью; координаты дополнительно проверяются по широким ограничивающим прямоугольникам, которые отсекают грубые ошибки, но не описывают точную геометрию границ. Места около границы нужно отдельно аудировать.

В текущих записях нет проверенных часов работы, цен, рейтингов, адресов бронирования, актуальности объекта, доступности для детей или транспортных переходов. Координата — точка Wikidata, а не навигационная проверка. Поэтому результаты можно использовать для поиска кандидатов и предварительного маршрута, но нельзя показывать как проверенный маршрут для поездки или как подтверждение доступности места.

Публичная выборка Wikidata неполная: в частности, она пока слабо покрывает Московскую область. Отсутствие места в снимке не означает, что такого места нет. Следующий шаг — расширить покрытие реестром OSM с устойчивого источника, затем дедуплицировать по Wikidata ID и отдельно проверять координаты, административную принадлежность и лицензии.

## Импорт и проверка

Обновить снимок из QLever:

```powershell
.\venv\Scripts\python.exe -B -m scripts.import_wikidata_places
```

Импортер сохраняет исходный SPARQL JSON в игнорируемый `data/raw/open-data/wikidata/` и атомарно обновляет нормализованный JSON. Для offline-пересборки:

```powershell
.\venv\Scripts\python.exe -B -m scripts.import_wikidata_places --input data/raw/open-data/wikidata/admin-pois.json
```

Проверить формы, provenance и cached provider:

```powershell
.\venv\Scripts\python.exe -B -m unittest tests.test_wikidata_import
```
